# BRIEFING HELL: La Venganza del UX

Videojuego arcade retro-corporate 2D desarrollado en HTML5 Canvas y Web Audio API.

## Controles
- **Moverse**: `A` / `D` o `◄` / `►`
- **Saltar**: `W` o `▲`
- **Fase 1 (Bat/Reflejo)**: `Espacio` o `Clic` (devuelve los briefings al cliente)
- **Fase 2 (Látigo USB-C 100W)**: `Espacio` o `Clic` (fustiga al Stakeholder Absoluto)

## Demo online
Activa GitHub Pages en `Settings -> Pages -> Branch: main / root`.
